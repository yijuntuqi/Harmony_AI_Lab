# 课后记商店文案

## 基本信息

- 应用名称：课后记
- 当前版本：1.0.0
- 建议分类：教育 / 效率
- 一句话简介：本地记录学生、课时与账目
- 数据方式：本地保存，无需注册，无广告

## 应用简介

课后记帮助家教和培训老师记录每节课、学生课时与收款情况。课后快速生成可编辑的家长反馈，减少手工整理账目的时间。

## 详细介绍

给学生建立独立档案，按小时或按次设置价格，支持后付结算和课时包两种记录方式。

每次上课后记录日期、时长或课次、掌握情况和薄弱点，费用或剩余课时自动更新。你可以修改或删除课程记录，并查看对应的历史明细。

课后反馈会根据当次记录生成，你可以编辑后复制，再粘贴到自己使用的沟通工具中。反馈只保存在本机，不会自动发送。

主要功能：

- 学生档案与课程价格管理
- 后付记课、收款和待收金额记录
- 课时包充值、扣课和剩余课时查询
- 家长反馈生成、编辑与复制
- 课程、收款、充值和反馈历史查询
- 本地保存，断网也能完成核心记录

## 权限与隐私说明

应用不申请网络、位置、通讯录、麦克风或相册等敏感权限。仅在用户主动复制反馈时写入系统剪贴板，不读取剪贴板。
